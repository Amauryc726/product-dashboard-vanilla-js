# Product Dashboard

## Description
This project is an interactive product dashboard built with HTML, CSS, and JavaScript. It was created to organize and display product information in a cleaner and more useful way.

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub

## How to View the Project
1. Open the repository.
2. Download or clone the project files.
3. Open `index.html` in a web browser.
4. Review the dashboard and how the product information is displayed.

## What I Learned
While building this project, I learned how to organize front-end files, connect JavaScript with a webpage, and create a more structured user interface. I also improved my ability to present a project professionally through GitHub.
